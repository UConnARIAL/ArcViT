# ArcViT

**Diversity Curated Pretrained Foundation Model for Very-High-Resolution Arctic Remote Sensing**

ArcViT is an Arctic-specific remote sensing foundation model developed using diversity-aware image curation and masked autoencoder (MAE) pretraining on very-high-resolution satellite imagery.

The framework supports downstream environmental mapping tasks, including ice-wedge polygons, retrogressive thaw slumps, tundra drainage networks, and infrastructure.

## Repository Status

This repository accompanies our ArcViT research manuscript. The source code is currently being organized and documented for public release.

Planned resources include:
- Diversity-aware data curation and clustering code
- Arctic MAE pretraining implementation
- Downstream fine-tuning and evaluation configurations
- Pretrained encoder weights, subject to licensing permissions
- Installation instructions and reproducibility documentation

## Data Availability

The original Vantor satellite imagery cannot be redistributed under the applicable data licensing agreements. Researchers may use the released implementation with their own appropriately licensed imagery.
